# CLAUDE.md

## Design System
Always read `DESIGN.md` before making any visual or UI decisions.
All font choices, colors, spacing, layout, motion, and aesthetic direction are defined there.
Do not deviate without explicit user approval.
In QA mode, flag any UI code that does not match `DESIGN.md`.

## SpecTwin UI Notes
SpecTwin is a Dear PyGui scientific desktop workstation, not a web dashboard or marketing site.
Prefer dense, calm, instrument-grade layouts built around plots, tables, parameters, and workflow state.
Avoid generic SaaS visual patterns, oversized cards, purple gradients, bubbly radius, and decorative UI that competes with scientific data.
